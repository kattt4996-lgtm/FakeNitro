FakeNitro

A plugin for Revenge / Bunny that brings profile themes, profile effects & frames, and cosmetic client-side Nitro unlocks to Discord Android.

Install Plugin View Source on GitHub
Revenge Bunny Discord Android Client-side only

What it does

Everything runs locally on your own client — nothing is sent to Discord's servers or changes what other users see unless they run the same plugin.

Profile Themes & Effects

Show custom profile theme colors, profile effects, and profile frames by hiding data in your About Me using invisible zero-width characters.

Unlock Emojis & Stickers

Optionally treat filtered, disabled, or premium-locked emojis and stickers as usable on your own client.

Premium Type Override

Locally display the premium badge/tier of your choice — None, Nitro Classic, Nitro, or Nitro Basic — purely cosmetic.

How to install

You need Revenge or Bunny already set up on Discord Android.

  1. Open Discord (with Revenge/Bunny installed)
  2. Go to Settings → Plugins
  3. Tap Install plugin / the + icon
  4. Paste the link below
  5. Confirm and enable the plugin
Note: If you landed here directly from a plugin link (like /FakeNitro/) and saw a 404 or raw code, that's expected — that URL is meant to be pasted into Revenge/Bunny's plugin installer, not opened as a webpage.
